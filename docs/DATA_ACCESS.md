# Data sources

HEAP redistributes none of these; point the variables in [`ENVIRONMENT.md`](ENVIRONMENT.md)
at your own copies.

| Data | Used for | Access |
|---|---|---|
| UK Biobank proteomics, exposures, covariates, outcomes, genotypes | Everything | Approved [UK Biobank application](https://www.ukbiobank.ac.uk/enable-your-research/apply-for-access) |
| OmicsPred protein score weights | cis/trans protein genetic scores | [omicspred.org](https://www.omicspred.org/) |
| UK Biobank Pharma Proteomics Project pQTL | Mendelian randomization | Public summary statistics |
| deCODE plasma pQTL | MR replication | [decode.com/summarydata](https://www.decode.com/summarydata/) |
| FinnGen disease GWAS | MR outcomes | [finngen.fi](https://www.finngen.fi/en/access_results) |
| 1000 Genomes EUR reference panel | MR clumping | Any EUR PLINK panel |
| LDSC EUR LD scores and HapMap3 SNP list | LD score regression | Distributed with [LDSC](https://github.com/bulik/ldsc) |
| HERITAGE exercise-training proteomics | Intervention comparison | [doi:10.1172/jci.insight.165867](https://doi.org/10.1172/jci.insight.165867) |
| Semaglutide trial proteomics | Intervention comparison | [doi:10.1038/s41591-024-03355-2](https://doi.org/10.1038/s41591-024-03355-2) |

**HEAP results** (summary statistics, Supplementary Tables and Data, PES weights):
[heap.bio](https://heap.bio).
