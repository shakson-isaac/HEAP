# HEAP LDSC workflow — heritability + genomic inflation for exposure GWAS

LD Score Regression (LDSC, Bulik-Sullivan et al. 2015) applied to the HEAP
**exposure GWAS** (REGENIE step 2; see `slurm/gwas_regenie/`). It gives, per
exposure:

- **SNP heritability** `h2` (observed scale) — how much of the exposure's
  variance is captured by common SNPs.
- **LDSC intercept** — a *model-based* genomic-inflation estimate. Unlike
  `lambda_GC` (from the QQ plot), the intercept separates true polygenic signal
  from confounding/population structure: intercept ≈ 1 means inflation is
  polygenicity, intercept > 1 flags confounding. This is the "second estimate of
  genomic inflation" alongside the QQ `lambda_GC` in `fig_gwas_qq`.
- (optional) **genetic correlation** `rg` between exposures.

LDSC is a *base method* (like REGENIE/GREML), so it lives at the repo top level
under `slurm/ldsc/` + `scripts/ldsc/`, not inside a numbered module.

## Layout

```
scripts/ldsc/
  run_ldsc_h2.sh        per-exposure pipeline: preprocess -> munge -> ldsc.py --h2
  collect_ldsc_h2.R     parse all h2 logs -> tidy ldsc_h2_summary.tsv
  collect_ldsc_rg.R     parse all rg logs -> tidy ldsc_rg_summary.tsv (pairwise)
slurm/ldsc/
  submit_ldsc.sh        ONE-COMMAND launcher (regenerates list, sizes + submits array)
  ldsc_h2_array.sh      SLURM array: one exposure per task -> run_ldsc_h2.sh
  ldsc_rg.sh            SLURM job: pairwise genetic correlations (after h2)
  ldsc_exposures.txt    generated by submit_ldsc.sh (completed exposure GWAS)
  ldsc_rg_exposures.txt curated well-powered exposures for rg (h2 z>=4 & h2>=0.02)
  environment.yml       conda recipe (python 2.7 + numpy/scipy/pandas/bitarray/pybedtools)
  environment_pinned.yml exact `conda env export` of the built env
```

## Figures (supplement/gwas/)

| figure_id | what | loader |
|---|---|---|
| `fig_ldsc_h2` | SNP heritability of the exposures (h2 + 95% CI, by category) | `load_ldsc_h2` |
| `fig_ldsc_intercept` | genomic inflation: polygenicity vs confounding (intercept vs lambda_GC) | `load_ldsc_h2` |
| `fig_ldsc_rg` | genetic correlation between exposures (clustered rg heatmap) | `load_ldsc_rg` |

Figure generation is not part of this code release; see "Release scope" in the README.

Every path is overridable via env vars (`LDSC_HOME`, `LDSC_LD_DIR`,
`LDSC_SNPLIST`, `LDSC_ENV`, `HEAP_REGENIE_STEP2_DIR`, `LDSC_OUT_ROOT`) — see the
header of `scripts/ldsc/run_ldsc_h2.sh`. The runner calls the env's python
directly (`${LDSC_ENV}/bin/python`), so no `conda activate` is required.

## Inputs / Outputs

- **Input**: `output/gwas/regenie_step2/<exposure>/<exposure>.regenie` (LOG10P is
  converted to P; effect allele = REGENIE `ALLELE1`).
- **Output** (under `${IGLOO}/UKB/HEAP/output/gwas/ldsc/`):
  - `munged/<exposure>.sumstats.gz` (+ `.log`) — HapMap3-filtered, reused by rg
  - `h2/<exposure>.log` — the heritability + intercept result
  - `rg/<root>.rg.log` — genetic-correlation tables (if `ldsc_rg.sh` run)
  - `ldsc_h2_summary.tsv` — tidy table from `collect_ldsc_h2.R`

## Run it

```bash
# 0. (rebuild the conda env only if IGLOO/envs/ldsc_env is missing)
#    module load conda/miniforge3/24.11.3-0
#    conda env create -p /n/groups/patel/IGLOO/envs/ldsc_env -f slurm/ldsc/environment.yml

# 1. submit the heritability array (auto-sizes to completed exposure GWAS)
slurm/ldsc/submit_ldsc.sh                 # add --rg to also queue genetic correlations
#   --dry-run to preview, --help for options

# 2. (single exposure, interactively / for testing)
HEAP_PATHS_FILE=$PWD/workflow/00_paths.R \
  bash scripts/ldsc/run_ldsc_h2.sh alcohol_intake_frequency_f1558_0_0

# 3. collect h2 results into one table once jobs finish
module load gcc/14.2.0 R/4.4.2
HEAP_PATHS_FILE=$PWD/workflow/00_paths.R Rscript scripts/ldsc/collect_ldsc_h2.R

# 4. genetic correlation (rg): curate slurm/ldsc/ldsc_rg_exposures.txt to the
#    well-powered exposures (h2 z>=4 & h2>=0.02), submit, then collect
sbatch slurm/ldsc/ldsc_rg.sh
HEAP_PATHS_FILE=$PWD/workflow/00_paths.R Rscript scripts/ldsc/collect_ldsc_rg.R

```

Resources per array task: 1 core / 16 GB / 2 h (`short`) — munge is the slow
step (~minutes on 7.8M variants). Re-running skips exposures whose `h2/<exp>.log`
already exists (`LDSC_FORCE=1` to redo).

## Notes / caveats

- LD reference is **EUR**; restrict to the EUR-ancestry GWAS (the HEAP exposure
  GWAS is EUR) or swap `LDSC_LD_DIR` for an ancestry-matched panel.
- `h2` is on the **observed scale**. For binary exposures (firth GWAS), convert
  to the liability scale with `--samp-prev`/`--pop-prev` if you need that — not
  applied by default here.
- rg is noisy for low-`h2` traits; curate `slurm/ldsc/ldsc_rg_exposures.txt`
  (one exposure id per line) rather than correlating everything.
