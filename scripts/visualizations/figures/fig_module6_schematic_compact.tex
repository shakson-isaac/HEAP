% A small, squarer "quick overview" version of the study-design schematic:
% timeline + one-line train/test note + PES -> three SHORT questions (no
% estimator subtext; that detail lives in the methods/caption). Squarer aspect
% (~1.25) so it sits as the small top-left quadrant of the main figure.
% Build: tectonic --outdir <dir> fig_module6_schematic_compact.tex
%        pdftocairo -svg / -png -r 200 -singlefile ...
%
% COHORT NUMBERS -- verified 2026-08-08 against split_df in HEAP.rds, which is the
% object Module 6 actually reads (split rule: scripts/loaders/HEAP_loader.R:894):
%   baseline i0 = 53,014 | train_baseline_only = 51,804
%   held out (has i2 or i3) = 1,254, of whom 1,210 have an i0 draw
%   51,804 + 1,254 = 53,058 with any proteomics; 53,014 of those have a baseline draw.
%   165 exposures scored across 13 categories (counts sum exactly; see NUM-4).
% These are COHORT counts and are not per-exposure. The per-exposure training N is
% 41,383-51,743 (median 51,259) after exposure missingness -- do NOT put one of those
% here. The previous values (45,839 / 44,629 / 164) were exactly that mistake: one
% exposure's complete-case count labelled as the study design.
%
% THE TWO IMAGING DROPLETS ARE THE SCORED SET, 1,169 and 1,112 -- deliberately, not
% the 1,172 and 1,123 that split_df reports as having a proteomic measurement. The
% difference is 14 person-visits from 13 people (3 at i2, 11 at i3) who were bled at
% that visit but have no row in the exposure long table for it, so the inner join at
% Module6_prod_longitudinal.R:567 drops them and nothing downstream can score them.
% Nothing is lost later to protein or covariate missingness. Using the scored set
% makes the panel agree with \Tref{pes_performance}: 1,210 + 1,169 + 1,112 = 3,491,
% which is exactly that table's n_obs, and 1,210 is \nTestPES. Author's call
% 2026-08-08: one set of numbers across every artifact beats a 3-and-11 discrepancy
% a reader cannot diagnose.
