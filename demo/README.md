# Demo: HEAP on synthetic data

Runs the unmodified HEAP analysis code, in the paper's order, on small synthetic
datasets. No UK Biobank data, cluster or SLURM needed.

> **The demo data are constructed examples, not real data.** Every value is generated by
> the scripts in this folder from a random seed; no UK Biobank or other participant data
> are used or derived from. The data exist for two purposes only: to confirm that the code
> runs end to end and recovers effects we planted on purpose, and to show the format each
> analysis expects its inputs in. The effect sizes are arbitrary, and the demo's results
> say nothing about real proteins, exposures or diseases.

```bash
bash demo/run_demo.sh              # every stage, writes ./heap_demo_run
bash demo/run_demo.sh m1 m2 m3     # selected stages
```

**Needs:** R 4.4.2 and the packages in `config/r_packages.tsv`
(`Rscript scripts/setup/install_r_packages.R`; set `HEAP_RLIB` if they are
in a non-default library). GREML also needs [GCTA](https://yanglab.westlake.edu.cn/software/gcta/)
and [PLINK 2](https://www.cog-genomics.org/plink/2.0/) (`GCTA_BIN`, `PLINK2_BIN`, or on `PATH`),
bash 4 and GNU `time`; without them that step is skipped. **Run time:** 14 minutes for all
stages on one core, 1.5 GB peak memory (measured on an Intel Xeon Platinum 8468 cluster
node, Linux): HEAP R² ~6 min, MR ~5 min, GREML ~2 min, the rest under 2 min.

## Stages

| Stage | Analysis (figure) | Runs | Planted | Expected result |
|---|---|---|---|---|
| `m1` | Variance decomposition (Fig. 1): HEAP predictive R² | `Module1_suggested.R` | Genetics 0.09, exposome 0.07, GxE 0.02 of variance | Held-out R²: genetics > exposome > GxE |
| | Variance decomposition (Fig. 1): GREML | `slurm/greml/*.sh` → GCTA REML with genetic, exposome and GxE kernels | G 0.30, E 0.25, GxE 0.10; 20 related pairs | G and E recovered; GxE imprecise at this size; one member of each related pair removed |
| `m2` | Exposure–protein associations (Fig. 2) | `Module2.R` | Two exposures and one gene × exposure interaction affect every protein | Both exposures detected; ~5% of the other exposure terms at p < 0.05; interaction detected for most proteins |
| `m3` | Mediation (Fig. 3) | `Module3.R` on the Module 1 scores | Only `protein_1` raises the risk of `disease_1`; `disease_2` depends on age only | A significant indirect effect for `protein_1` on `disease_1` only |
| `mr` | Mendelian randomization (Fig. 4) | `Module5.R` (UK Biobank pQTL arm) and `Module5_deCODE.R` on synthetic GWAS summary statistics, then `build_mr_tables.R`, `compare_arms.R`, `summarize_mr_triads.R` | Four triads `exposure_k → protein_k → disease_k`: a true mediator, reverse causation, unresolved Steiger direction, failed colocalization | One Tier 1 mediator; the others classed Reverse, Suggestive and Tier 2 |
| `m6` | Proteome-based exposure score (Fig. 6) | `Module6_prod_longitudinal.R` for one exposure | The exposure changes between visits (r = 0.7) and the proteins follow it | Held-out R² > 0 at every visit, ~0 for covariates alone; the score's change tracks the exposure's change |

`demo/summarize_demo.R` prints each stage's estimates next to the planted values. Outputs
use the layout of a full run, under `heap_demo_run/igloo/UKB/HEAP/output/` (GREML under
`heap_demo_run/greml/`); each step's log is `heap_demo_run/<step>.log`.

## Data

All data are simulated, with generic labels (`protein_1`, `exposure_1`, `disease_1`) so
that no result can be mistaken for a real protein, exposure or disease. Only the data's
*structure* mirrors a real run: file formats, column names, the 169 exposures' categories
and types, and the covariate names. Use these files as a template for arranging your own
data. The code runs from `heap_demo_run/repo/`, which
links to this repository's code and holds a copy of `config/` whose exposure and protein
lists carry those labels.

- `make_synthetic_heap.R`: the analysis dataset
  ([structure](../docs/REPRODUCIBILITY.md#the-analysis-dataset)). 2,000 participants, 169
  exposures in the real categories and with the real types, the `base` covariates,
  6 proteins with cis and trans genetic scores, 2 incident diseases, and repeat visits for
  20% of participants.
- `make_synthetic_greml.R`: genotypes for GREML. 4,000 participants and 50,000 SNPs in
  PLINK 2 format; proteins built from genetic, exposome and GxE components. GxE is weakly
  identified at this size, so estimates vary with the random seed; the default seed gives
  converged fits for all three proteins.
- `make_synthetic_gwas.R`: GWAS summary statistics in the formats `Module5.R` reads
  (regenie exposures, UK Biobank and deCODE pQTL, FinnGen diseases), generated from a
  synthetic LD reference panel (10,000 people, 900 SNPs) that is also used for clumping.
  Colocalization results are supplied as a table rather than computed.

Exact values depend on the random seed and package versions.
